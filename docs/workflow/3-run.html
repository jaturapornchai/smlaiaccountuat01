📄สคริปต์ทดสอบ

uat-scripts/*.json 31 ชุด บอกโมดูล มุมตรวจ และขั้นตอน · AI เพิ่มเองได้ด้วย save_script

⏳คิวรัน

รันพร้อมกันสูงสุด 3 รอบ (ตั้งได้ 1–10) รอบอื่นรอคิว

🦾ตัวรัน

runner/run.mjs ทำตามสคริปต์ทีละขั้น เก็บผลไว้ที่ runs/<id>/

🖥️หน้าเว็บ

รับผลทีละบรรทัด → ไทม์ไลน์ คาดหวังเทียบจริง จอสด ภาพหลักฐาน

ชนิดของขั้นตอน (ทำกับระบบจริงทั้งหมด)

🖱️หน้าจอ ui.*

Chrome ผ่าน Playwright เปิดเมนู กรอก กด เลือก แล้วตรวจข้อความ/ค่า · ถ่ายจอสดทุกขั้น

🧹จอต้องสะอาด

ui.expectClean ไม่มี HTTP 4xx/5xx ไม่มี error ใน JS/console และไม่มีข้อความ error ฐานข้อมูลบนจอ

🔗API api.request

เรียก API จริง ตรวจสถานะ HTTP และค่าใน JSON แล้วเก็บคำขอ-คำตอบเป็นหลักฐาน

🐘ฐานข้อมูล

db.query / db.exec ผ่าน psql ตรวจค่าทีละแถว · ยอมให้แตะฐาน smldemo เท่านั้น

🧽 ขั้น cleanup รันเสมอแม้ขั้นหลักพัง เพื่อเก็บกวาดข้อมูลทดสอบ

✅ผ่านทุกขั้น

บันทึก run.json + หลักฐาน NNN-*.png / json · ถ้าเคยเปิด issue ไว้ ระบบคอมเมนต์ว่าตรวจซ้ำผ่านแล้ว

❌ไม่ผ่าน

ถ่ายภาพตอนพัง ขั้นที่เหลือข้าม · สมอง AI วิเคราะห์ → เปิด issue ใน IssueMate (เมื่อเปิดส่งอัตโนมัติไว้)
